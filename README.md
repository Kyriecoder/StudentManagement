# 学生成绩管理系统

这是一个使用 C++ 编写的控制台学生成绩管理系统，用于练习链表、二叉搜索树、哈希表和稳定排序算法。

项目将完整学生信息保存在学生主链表中，并通过学号 BST、姓名 HASH 和总分排名链建立辅助索引，避免重复保存完整学生数据。

## 功能

- 录入学生信息，自动检查学号是否重复
- 检查四门成绩是否在 0～100 范围内
- 自动计算四门课程总分
- 按学号查询学生
- 按姓名查询并输出全部同名学生
- 按学号修改四门课程成绩
- 修改成绩后自动更新排名
- 按学生录入顺序输出全部信息
- 按总分从高到低输出排名
- 按学号删除学生
- 支持竞赛排名规则，例如 `1、2、2、4`
- 支持非法菜单和非法成绩输入处理

## 数据结构设计

系统包含四个核心数据结构：

| 数据结构 | 保存内容 | 主要用途 |
|---|---|---|
| `StudentList` | 完整学生信息 | 保存全部学生数据 |
| `StudentBST` | 学号和学生节点指针 | 按学号快速查询 |
| `NameHash` | 姓名和学生节点指针 | 按姓名查询全部同名学生 |
| `RankList` | 学生节点指针和排名顺序 | 维护总分排名 |

结构关系如下：

```text
                     StudentManager
                           │
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
    StudentList       StudentBST         NameHash
    完整学生数据        学号索引           姓名索引
         │                 │                 │
         └─────────────────┼─────────────────┘
                           ▼
                        RankList
                        总分排名
```

完整学生信息只在 `StudentList` 中保存一次。BST、HASH 和排名链都只保存指向学生节点的指针。

## 核心类

### `Student`

保存一个学生的完整信息：

- 学号
- 姓名
- 性别
- 英语成绩
- 数学成绩
- 程序设计成绩
- 数据结构成绩
- 总分
- 排名
- 录入顺序

学号和姓名在创建后不提供修改函数，修改功能只修改四门课程成绩。

### `StudentList`

使用单链表保存学生，包含头指针、尾指针和学生数量。

- 尾部插入时间复杂度为 O(1)
- 按学号顺序查找为 O(n)
- 删除学生节点时为 O(n)
- 负责释放全部 `StudentNode`

### `StudentBST`

使用学号作为关键字建立二叉搜索树。

- BST 节点只保存学号和学生节点指针
- 学号不允许重复
- 平均查找复杂度为 O(log n)
- 最坏情况下可能退化为 O(n)

### `NameHash`

使用姓名作为哈希关键字，采用链地址法。

- 固定使用 101 个哈希桶
- 同名学生会保存为多个不同的哈希节点
- 查询时需要比较完整姓名
- 不同姓名发生哈希冲突时仍能正确查询

### `RankList`

使用双向链表维护排名顺序。

- 第一次建立排名时使用稳定二路归并排序
- 总分相同时按录入顺序排列
- 使用竞赛排名规则
- 新增、修改和删除学生后只进行局部排名调整
- 不调用 `std::sort()` 等现成排序函数

## 排名规则

排名按照总分从高到低计算。

总分相同时，学生共享相同名次，后面的名次会跳过被占用的位置：

```text
总分：95、90、90、85
排名：1、 2、 2、 4
```

排名保存在每个 `Student` 对象的 `rank` 成员中，排名链只负责维护学生的先后顺序。

第一次建立排名时使用稳定二路归并排序。之后：

- 新增学生：插入到排名链的合适位置
- 修改成绩：从原位置摘下学生，再按新总分重新插入
- 删除学生：从排名链中摘除对应节点
- 局部修改后：只从最早受影响的位置开始重新计算名次

## 主要操作流程

### 录入学生

```text
输入学号、姓名、性别和四门成绩
→ 检查学号是否重复
→ 检查成绩范围
→ 创建学生信息
→ 加入学生主链表
→ 加入学号 BST
→ 加入姓名 HASH
→ 插入排名链
→ 输出录入结果
```

### 按学号查询

```text
输入学号
→ 在 BST 中查找
→ 找到后输出学生信息
```

### 按姓名查询

```text
输入姓名
→ 计算哈希桶
→ 遍历冲突链
→ 输出全部同名学生
```

### 修改成绩

```text
输入学号
→ 在 BST 中找到学生
→ 输入四门新成绩
→ 检查成绩范围
→ 重新计算总分
→ 调整排名链中的位置
→ 重新计算受影响的名次
```

### 删除学生

删除顺序如下：

```text
从排名链删除
→ 从姓名 HASH 删除
→ 从学号 BST 删除
→ 最后从学生主链表删除 StudentNode
```

最后删除主链表节点，是为了避免其他索引结构中留下悬空指针。

## 内存管理

- `StudentList` 拥有并释放全部 `StudentNode`
- `StudentBST` 只释放自己的 `BSTNode`
- `NameHash` 只释放自己的 `HashNode`
- `RankList` 只释放自己的 `RankNode`
- BST、HASH 和排名链都不得释放它们指向的 `StudentNode`

如果没有先清理各个索引，就直接删除主链表节点，其他结构会产生悬空指针。

## 时间复杂度

| 操作 | 时间复杂度 |
|---|---|
| 按学号查询 | 平均 O(log n)，最坏 O(n) |
| 按姓名查询 | 平均 O(1 + 哈希冲突链长度) |
| 追加学生 | O(1) |
| 建立排名 | O(n log n) |
| 插入排名 | O(n) |
| 修改后调整排名 | O(n) |
| 删除排名 | O(n) |
| 输出全部学生 | O(n) |
| 输出排名 | O(n) |

排名更新中的 O(n) 主要是查找位置和重新计算受影响的排名，不会再次执行完整排序。

## 编译和运行

### Visual Studio

1. 使用 Visual Studio 2022 打开 `StudentCalss_Mangement_System.sln`
2. 选择 `x64` 和 `Debug` 或 `Release`

## 测试建议

- 录入重复学号，确认系统拒绝
- 录入超过 100 或小于 0 的成绩，确认系统拒绝
- 录入多个同名学生，确认按姓名查询能全部输出
- 修改成绩，确认总分和排名自动变化
- 测试同分排名是否为 `1、2、2、4`
- 删除第一名、中间一名和最后一名
- 删除后再次查询，确认 BST、HASH 和排名链不存在悬空记录
- 输入非数字菜单选项，确认程序不会进入死循环

## 当前限制

- 数据只保存在内存中，退出程序后不会自动保存
- BST 没有做平衡处理，特殊录入顺序下可能退化为链表
- 哈希表固定使用 101 个桶，没有实现动态扩容
- 姓名比较和哈希按照当前字符串编码的字节进行计算

如果需要退出后保留数据，可以继续增加：

- `saveToFile()`
- `loadFromFile()`
- 启动时自动加载
- 退出前自动保存
